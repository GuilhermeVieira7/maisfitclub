# +Fit Club Academia — site

Site estático (HTML + CSS + JS puro), pronto pra Vercel sem build.

Tudo que muda fica no topo do `script.js`: `UNIDADES` (endereço e WhatsApp de cada unidade), `MODALIDADES`, `MOTIVOS`, `AVALIACAO` e `ABERTO` (horário de acesso usado no selo "Aberto agora"). Preços e horários dos planos ficam no `index.html` (seção `#planos`).
