# +Fit Club Academia — site

Site estático (HTML + CSS + JS puro), pronto pra Vercel sem build. Todas as fotos e vídeos são da própria academia (extraídos dos vídeos oficiais).

Tudo que muda fica no topo do `script.js`:
- `UNIDADES` — endereço, WhatsApp e foto (`foto`) de cada unidade
- `GOOGLE_REVIEWS` — link do perfil no Google (avaliações)
- `DEPOIMENTOS` — depoimentos reais de alunos (a seção só aparece quando houver)
- `CATEGORIAS` — modalidades, descrições, benefícios e em quais planos entram
- `AVALIACAO` — etapas da avaliação física
- `ABERTO` — horário de acesso usado no selo "Aberto agora"

Preços e horários dos planos ficam no `index.html` (seção `#planos`).
